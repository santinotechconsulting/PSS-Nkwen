# WordPress Administrator & Editor Manual
## Presbyterian Secondary School (PSS) Nkwen
**Developed by Santino Tech Consulting - "We Build Your Digital Presence"**

This manual instructs designated school staff, vice-principals, secretaries, and IT officers on managing the school's public website through the WordPress administration interface.

---

## 1. Logging Into WordPress
1. Open your browser and navigate to: `https://cms.pssnkwen.edu.cm/wp-admin` (or your configured WordPress domain).
2. Enter your assigned username and password.
3. If two-factor authentication is configured, enter the verification code.
4. *Important Security Rule:* Never share administrative credentials or reuse passwords across multiple staff members.

---

## 2. Managing News & Announcements
1. Click **Posts > Add New** in the left sidebar.
2. In the title field, enter the headline (e.g. *"First Term Examination Timetable Notice"*).
3. In the content editor, compose the announcement text.
4. In the right panel under **Categories**, check the appropriate box:
   - *Academic News*
   - *School Announcements*
   - *Student Activities*
5. Under **Featured Image**, click **Set featured image** and upload a clear, approved photograph.
6. Under **Excerpt**, write a 1–2 sentence summary that will appear on card previews.
7. Click **Publish**. The announcement will appear automatically on the website homepage and news page.

---

## 3. Managing School Events & Calendar
1. In the sidebar, click **School Events > Add New**.
2. Enter the event title.
3. In the event details box, configure:
   - **Event Date:** (e.g. `2026-11-14`)
   - **Time:** (e.g. `09:00 AM - 01:00 PM`)
   - **Venue:** (e.g. `School Chapel Pavilion` or `Main Sports Field`)
   - **Category:** (Academic, Spiritual, Sports, Administrative, or Community)
4. Add a concise description explaining who should attend.
5. Click **Publish**.

---

## 4. Uploading Public Documents & Forms
1. In the sidebar, click **Public Documents > Add New**.
2. Enter the title of the document (e.g. *"2026/2027 Admission Application Checklist"*).
3. Upload the official PDF file via the WordPress Media Library.
4. Select the document category (Admissions, Academic, Policies, or Notices).
5. Click **Publish**. The file is instantly accessible on the `/downloads` page.

---

## 5. Reviewing Admission & Contact Enquiries
1. In the sidebar, click **PSS Nkwen Desk > Enquiries Log**.
2. A table will display all submissions received from parents and guardians:
   - Date and time
   - Unique tracking reference code (e.g. `PSS-ADM-XXXXXX`)
   - Parent / guardian name
   - Telephone number
   - Prospective candidate name and intended class
   - Message details
3. *Confidentiality Notice:* These records are classified as private school correspondence and must not be shared outside authorized administrative staff.

---

## 6. Staff Accounts & Least-Privilege Roles
- **Administrator**: Dedicated solely to IT officers and the principal. Can update plugins and core settings.
- **Editor**: Senior administrative officers. Can publish and edit all posts, events, and documents.
- **Author**: Department heads or teachers submitting departmental updates for review.

---

## 7. Backups and Maintenance
- Run WordPress plugin and translation updates monthly.
- Before running major core updates, generate an on-demand database backup in Hostinger hPanel.
